# hop

**Your other computers, one tab away.**

Hop puts the terminals, files, web pages and apps of every machine you own in one fast window.
Mac, Linux and Windows, driven by your keyboard and by your AI tools.

[hopterm.com](https://hopterm.com) · [Docs](https://hopterm.com/docs/)

</div>

---

- **Just SSH.** Nothing to install on the other machine to get started.
- **Terminals that outlive the window.** Sessions keep running on their machine; pick them up from anywhere.
- **Files like they're local.** Browse, open, drag and drop across machines.
- **Web pages from over there.** A dev server on another machine opens in a tab, no port forwarding.
- **Another computer's apps.** Stream a window, or a game with a controller, with sound, at low latency.
- **Search everything.** One palette for every machine's files, sessions and windows.
- **Built for agents.** Your AI tools get the same reach you have, through MCP, a CLI and an API.
- **Everything is programmable.** One command list behind the app, the CLI, the API and the SDKs.

**Hop is in private testing and isn't out yet.** Follow along at [hopterm.com](https://hopterm.com).
